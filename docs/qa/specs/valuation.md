# Valuation

Market values for the collection, as estimates with their source and date (`HANDOVER.md` §6). Seeded by the valuation project (#207). Values are private unless the owner shows them (`[PUB-17]` onwards). Every clause is `[seed]` until a human promotes it (`K-SPEC-8`).

**Id prefix:** `VAL`

## The price source

- `[VAL-1]` `[seed]` Every BrickLink request goes through one client that signs it with OAuth 1.0a (HMAC-SHA1) from the four SST secrets `BrickLinkConsumerKey`, `BrickLinkConsumerSecret`, `BrickLinkTokenValue` and `BrickLinkTokenSecret`, named in `docs/deploy.md` (`[PLAT-3]`). It sets a timeout of at most 10 seconds, sends at most one request per second from each server instance, retries a 429 or 5xx answer at most twice with backoff that honours `Retry-After`, never retries past the caller's time budget, and never logs a secret, a signature or a signed URL.
- `[VAL-2]` `[seed]` A price is BrickLink's price guide for the item: `guide_type=sold`, the average over its last six months, `new_or_used` `N` for a sealed set and `U` for a used one, in the deployment's currency (`PLINTHOS_CURRENCY`, default `EUR`). Each is stored in `price_quote` with the item type and number, new or used, the average, the sample size, the currency, the source and when it was fetched. A set's type is `SET` and its number its set number, except in a series of collectible minifigures, where BrickLink numbers a figure `<box>-<n>` as `<prefix>-<n>` and the random bag `<box>-0` as `<box>-1`, and never by Rebrickable's own number. The prefix comes from Rebrickable's theme: `Series N Minifigures` is `col<N, two digits>`, `Disney Series N` is `coldis` and `Marvel Series N` is `colmar` (each with `N` from the second series on), and `Disney 100` is `coldis100`; a minifigure's type is `MINIFIG` and its number its reference number, and a minifigure without one has no price.

## Refreshing

- `[VAL-3]` `[seed]` Prices are refreshed only when the owner presses **Refresh prices** on `/admin`, never on a schedule and never on a public view (`HANDOVER.md` §6, `[PLAT-7]`). `startPriceRefresh` is a typed service function with zod-validated input that only an authenticated admin can call. It takes a scope (sets and minifigures, parts, or everything) and whether to ask for every price, records a run, and starts the background job (`[VAL-9]`); the owner may close the page. The job asks for each quote the scope needs once, oldest first. A quote asked for in the last 7 days is not asked for again unless the owner asks for every price.
- `[VAL-4]` `[seed]` A refresh that fails for one quote, unknown to BrickLink or refused, records that on the quote and goes on with the rest. One that fails for every request, a refused key or BrickLink unreachable, stops the run with the reason, which `/admin` shows, and logs `price.refresh.failed` with the reason and never a secret. A failed refresh never deletes or changes a price it already had.

## Values

- `[VAL-5]` `[seed]` An item's value is its manual override when the owner set one; otherwise its price for its condition × its quantity, adjusted by the percentage the owner set for its condition (`USED_WITH_BOX` and `USED_NO_BOX`, default 0 %); otherwise none. A minifigure is priced like a set when it has a reference number (`[VAL-2]`); a bulk lot or an `OTHER` item has a value only from its override. Every value carries its source (`BrickLink`, `override` or none) and, for a BrickLink one, the date of its quote.
- `[VAL-6]` `[seed]` A parts lot's value is its BrickLink average for its item type, number, colour and new or used (`[VAL-8]`) × its quantity, when the quote has an average. Otherwise it is the file's unit price × its quantity, when the file's currency is the deployment's, or the file names none (a BrickLink XML export never does), which is taken to be in the deployment's, as today. Otherwise the lot has none. The loose parts' value is the sum over the lots that have one, in the deployment's currency, with the number of lots valued from BrickLink, from the file, and not at all.
- `[VAL-7]` `[seed]` `/admin` shows each item's value and its source and date, and a total per segment: sealed, used and parts. The edit form takes a manual override, which is private; `/admin/settings` takes the per-condition adjustments. None of this reaches the public catalogue unless a setting shows it (`[PUB-17]`).

## The parts and the background job

- `[VAL-8]` `[seed]` A parts lot is priced from BrickLink's price guide (`[VAL-2]`'s average, currency and new or used, `N` for a new lot and `U` for a used one) by its item type, item number and, for a part, its colour. One letter maps to one BrickLink type: `P` part, `M` minifigure, `S` set, `B` book, `G` gear, `C` catalog, `I` instruction and `O` original box. A lot of any other type has no BrickLink price. Each quote is stored once in `part_price_quote` by item type, number, colour and new or used, however many lots share it, with the same fields and rules as `price_quote`.
- `[VAL-9]` `[seed]` The background job is a server function with no URL, which only the admin's server and the job itself may invoke. Its input is the run's id alone, and it does only what that run's row says. One run at a time holds the lease: a run is started only when none is running, and a running run whose heartbeat is older than 20 minutes is taken as stalled. `/admin` shows it as stopped, it logs `price.refresh.failed` with `stalled`, and a new run may start. Each invocation works for at most about 13 minutes, writing each answer and the heartbeat as it goes. It then invokes itself for the rest, or ends the run as done when nothing is left. A stop the owner asks for ends the run before the next request. The job never starts on its own and never runs after its run has ended.
- `[VAL-10]` `[seed]` Every BrickLink call is counted per UTC day. A run stops with `daily-limit` before a call would exceed 4,500 for the day, and logs `price.refresh.failed` with that reason. `/admin` says that pressing **Refresh prices** again after midnight UTC carries on where it stopped, because the quotes already asked for are within the 7 days.
- `[VAL-11]` `[seed]` `/admin` shows the running run's progress (done, failed and left) while the page is open, refreshed every few seconds, with **Stop**, and the last run's outcome after it ends: done, stopped by the owner, stopped with a reason, the daily limit or stalled. `/admin/parts` shows the parts value by source (BrickLink, file, none) and the lots, 100 to a page, each with its unit price, value, source and, for a BrickLink price, its date. None of it reaches the public catalogue unless a setting shows it (`[PUB-17]`).
